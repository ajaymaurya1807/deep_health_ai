# Deep Health AI

High-fidelity interactive mobile web prototype based on the supplied Google Stitch design.

## Local preview

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Open <http://localhost:4173>.

## Production build

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

The client demo is deployed automatically through GitHub Pages.
